# Checklist

## 图层与固定
- [x] 猜你想问渲染在卡片上层，重叠时仍可点击
- [x] 分支输入条不被卡片或猜你想问遮挡
- [x] 卡片顶部最右固定按钮存在，固定时图标高亮
- [x] 固定卡片不能被直接拖动；刷新后固定状态保持
- [x] 元卡片新建时默认固定，可手动解除

## 分支入口与连线
- [x] 分支按钮点击后在父卡片下方出现长条输入框，文案「请输入你的分支问题」并自动聚焦
- [x] 输入框回车后消失并生成回答卡片；可连续点击生成多条分支
- [x] 直接分支：子卡片在下方时从父下边中点出线，在上方时从上边中点出线
- [x] 共用母线：父右侧水平引线 + 纵向母线 + 子卡片左侧中点
- [x] 设置 → 画布 可在两种连接方式间切换，界面不出现 A/B 代号
- [x] 主链条（第一个子卡片）仍保持从左到右连接

## 自动整理
- [x] 共用母线模式下，猜你想问作为独立条目参与布局，卡片与猜你想问互不重叠
- [x] 直接分支模式下，主干水平、fork 子树整体排在父树下方，且与猜你想问不重叠
- [x] 两种模式的整理结果与当前连接方式一致（选 A 不会排成 B）
- [x] 整理后任意两张卡片/猜你想问矩形不重叠，主干与 fork 可区分
- [x] Ctrl+Z 可撤销自动整理，坐标完整还原
- [x] 笔记卡片不参与自动整理，维持原位

## 撤销
- [x] Ctrl+Z 连续撤销多次拖动，每次回退一步
- [x] 撤销深度取设置值（默认 10，最小 1），保存不清空撤销栈
- [x] 撤销「新增卡片」：已回答询问、生成中终止并删除、空白直接删除
- [x] 撤销「删除」可完整恢复最近一次删除批次（多卡片/多子树）
- [x] 撤销包含标题、pin、建议、自动整理、笔记编辑与尺寸
- [x] 撤销按画布隔离：切到 B 不能撤销 A；切回 A 可继续撤销
- [x] 刷新页面后撤销栈清空（仅会话内）
- [x] 个人设置（尺寸/主题/连线样式/保存参数）不进入撤销栈

## 保存
- [x] Ctrl+S 保存当前画布完整快照，文件写入 `backend/data/saves/`，单文件覆盖
- [x] 设置 → 保存 可修改自动保存间隔（默认 5 分钟，0=关闭）与保存步数（默认 10，最小 1）
- [x] 自动保存按设置间隔触发；0 时不触发
- [x] 保存成功有轻提示；保存不影响撤销
- [x] 保存目录与数据库均在 .gitignore 覆盖范围内

## 画布手势与选择
- [x] 空格+左键、鼠标中键可平移；普通左键拖空白不平移
- [x] 空白长按可平移，等待时间默认 300ms 且可在 设置 → 移动 修改
- [x] 滚轮缩放仍可用
- [x] Ctrl+左键多选/取消多选；普通点击卡片变为单选；空白点击清空
- [x] 只有标题区域能拖动卡片；未选中时直接按住标题即可拖动
- [x] 多选后拖动任一选中卡片，全部选中卡片及其子树一起移动
- [x] 多选浮动菜单含「删除所选」，存在未选中后代时二次询问；确认删除整棵分支，取消不删
- [x] 元卡片解除固定后可移动

## 标题、缩放与吸附
- [x] 双击标题进入编辑，Enter/失焦提交、Esc 取消
- [x] 标题修改后可撤销，修改时间同步更新
- [x] 缩放命中区为四边+四角：上下边只调高、左右边只调宽、角同时调整
- [x] 聊天卡片缩放作用于所有画布；笔记卡片缩放只作用于自身
- [x] 最小尺寸 280×240，无上限：不再出现单独两条调整线
- [x] Shift 拖动吸附 20px 网格并对齐其它卡片边缘/中心线（≤8px）
- [x] 拖动缩放手柄不会移动卡片

## 连线绕行
- [x] 连线最短路径穿过其它卡片时自动上/下绕行
- [x] 主链、分支、母线、ghost 连线均不穿过卡片

## 外观
- [x] 设置 → 外观 提供主题色相滑条与 0–360 数值输入，默认当前青色
- [x] 色相调整立即作用于强调色并持久化
- [x] 可修改连线粗细与颜色，所有连线立即生效并持久化
- [x] 主题模式提供 跟随系统（默认）/ 浅色 / 深色，切换立即生效
- [x] 跟随系统时随操作系统深浅色实时切换
- [x] 浅色主题下文字对比度可读、无深色残留
- [x] 时间制式可切换 24h / 12h（12h 显示 AM/PM）并持久化

- [x] 笔记可编辑标题与正文，拥有独立尺寸
