# v0.1.0 画布交互与外观 Spec

change-id: `canvas-ux-v010`

## Why

当前画布在重叠层级、分支入口、自动整理、拖拽与选择规则上存在体验断层；缺少撤销、保存、主题与笔记能力。本迭代集中修复这些问题，并把交互规则补齐到接近桌面级节点编辑器的手感。

## What Changes

- 修复「猜你想问 / 分支输入」与卡片的图层重叠；新增卡片固定（pin）能力。
- 分支入口改为卡片下方的长条输入框，回车后才生成回答卡片；分支连线支持「直接分支 / 共用母线」两种方式。
- 自动整理把「猜你想问」当作独立卡片参与布局，并按当前连接方式生成不重叠、可区分 fork 的排版。
- 新增按画布隔离的撤销（Ctrl+Z，步数可配）、手动/自动保存（Ctrl+S，自动间隔可配）。
- 标题双击编辑、画布平移规则、卡片多选与批量删除、连线绕行、边角缩放、Shift 吸附。
- 外观设置：主题色相、连线粗细/颜色、跟随系统/浅色/深色、时间显示 12/24 小时制。
- 新增笔记卡片（双击空白画布创建，独立尺寸）；每张卡片外右下角显示最新修改时间。
- 版本升至 `0.1.0`，中英 README 同步 changelog。

## Impact

- 后端：`models.py`（节点新增 `pinned`、`node_type`、`width/height`；设置新增连接方式、移动、保存、外观字段）、`schemas.py`、`services/settings.py`、`api/nodes.py`（pin/标题/正文/笔记/批量恢复）、`api/projects.py`（保存快照、笔记创建）、`db.py`（旧库补列）、`tests/`
- 前端：`store/graphStore.ts`（撤销栈、多选、pin、笔记、尺寸）、`canvas/*`（CardNode、NoteNode、Ghost、边组件、Canvas 交互）、`components/SettingsDialog.tsx`、`styles/theme.css`、`api/*`
- 文档：`readme.md`、`readme_en.md`、`frontend/package.json`

## 关键决策与假设

| 议题 | 决定 |
| --- | --- |
| 连接方式命名 | 设置中显示「直接分支（默认）」与「共用母线」（不再使用「引线后分支」）。 |
| 直接分支 | 从父卡片上/下边中点直接连线到子卡片；子卡片位于父卡片下方时从下边出，位于上方时从上边出，默认下方。 |
| 共用母线 | 父卡片右侧先引出水平引线，接到一条纵向母线，再从母线分叉到各子卡片的左侧边中点。 |
| 连接方式作用范围 | 只影响「分支边」（同一父卡片的第 2 个及以后的子卡片）；主链条（第一个子卡片）始终保持从左到右。 |
| 分支子卡片落点 | 默认在父卡片正下方：`x` 与父卡片相同，`y = 父.y + 卡片高度 + 100`；水平上不再排到右侧。 |
| 固定（pin） | 固定只约束**手动拖动**：固定卡片不能被直接拖起；若它的祖先被拖动，它作为子树成员仍跟随。自动整理不受 pin 限制。 |
| 元卡片 | 新建画布时根卡片默认 `pinned=true`；用户可点击固定图标解除。 |
| 撤销范围 | 仅「画布内容」：位置、标题、正文、pin、建议、自动整理结果、笔记的创建/编辑/尺寸、删除。**不包含**个人设置（全局卡片尺寸、主题、连线样式、保存/撤销参数、时间制式、连接方式）。 |
| 撤销存储 | 仅内存、按画布隔离；刷新或关闭页面后清空。切换画布再切回仍可撤销该画布。 |
| 撤销深度 | 取设置「保存步数」，默认 10，最小 1；保存（手动/自动）不改变撤销栈。 |
| 删除撤销 | 仅恢复**最近一次删除批次**（一次删除多张卡与多棵子树视为一批），恢复完整内容与坐标。 |
| 新增卡片撤销 | 已回答 → 询问是否删除；生成中 → 终止流式并删除；空白输入卡片 → 直接删除。 |
| 保存 | 只保存当前画布的完整节点集合到 `backend/data/saves/{projectId}.json`，覆盖同一文件，仅保留 1 份；自动保存间隔 0 表示关闭。 |
| 笔记卡片 | 独立 `node_type='note'`，拥有自己的宽高；不共享全局卡片尺寸、不参与自动整理、不生成连线、不产生建议。其余（选择、多选删除、pin、撤销、修改时间）与聊天卡片一致。 |
| 修改时间 | 取节点 `updatedAt`，按本地时区格式化 `yyyy-mm-dd hh-mm`；12 小时制追加 `AM/PM`；显示在卡片外部右下角。 |
| Shift 吸附 | 拖动时按住 Shift：位置吸附到 20px 网格，并在与其它卡片边缘/中心线距离 ≤ 8px 时对齐；连线拐点由卡片位置派生，随之对齐。 |
| 平移与缩放 | 平移仅通过 空格+左键 / 鼠标中键 / 空白长按（默认 300ms，可在设置调整）；滚轮缩放保留。左键单击空白取消选择。 |
| 多选 | Ctrl+左键切换选中；点击未选中的卡片（不按 Ctrl）清空其它选中。拖动已选卡片时，选中卡片及其子树一起移动（去重）。 |
| 删除确认 | 若待删除集合存在未被选中的后代，先询问；选「是」连同分支删除，选「否」取消。 |

## ADDED / MODIFIED Requirements

### Requirement: 图层层级与固定

猜你想问与分支输入条 SHALL 渲染在卡片之上；每张卡片 SHALL 提供固定按钮并持久化固定状态。

#### Scenario: 猜你想问不被卡片遮挡
- **WHEN** 拖动一棵子树使其与另一棵子树的猜你想问区域重叠
- **THEN** 猜你想问完整显示在卡片上层，可正常点击

#### Scenario: 分支输入条不被遮挡
- **WHEN** 分支输入条与猜你想问同时出现且位置重叠
- **THEN** 输入条可点击、可输入，不被卡片遮住

#### Scenario: 固定卡片
- **WHEN** 点击卡片顶部最右侧的固定图标
- **THEN** 图标切换为高亮态，该卡片不能再被直接拖动；再次点击解除
- **AND** 刷新后固定状态保持；元卡片新建时默认固定

### Requirement: 分支输入与连接方式

点击分支按钮 SHALL 在父卡片下方生成一条长条输入框（文案「请输入你的分支问题」，自动聚焦）；回车后才创建卡片。分支连线样式 SHALL 支持直接分支与共用母线两种，并可在设置切换。

#### Scenario: 分支输入
- **WHEN** 点击卡片底部分支图标
- **THEN** 卡片下方出现长条输入框并自动聚焦，用户可直接输入
- **AND** 按 Enter 后输入框消失并在父卡片下方生成回答卡片；再次点击可生成另一条分支输入框

#### Scenario: 直接分支
- **WHEN** 连接方式为「直接分支」
- **THEN** 分支边从父卡片上/下边中点连到子卡片上/下边中点；子卡片在下方时从下边出线，在上方时从上边出线

#### Scenario: 共用母线
- **WHEN** 连接方式为「共用母线」
- **THEN** 父卡片右侧引出水平引线，接到统一纵向母线，再分叉到各子卡片左侧中点

### Requirement: 自动整理

自动整理 SHALL 把猜你想问视为独立卡片占位，保证任意卡片/猜你想问之间不重叠，并区分 fork 与主干；排版结果 SHALL 与当前连接方式一致。

#### Scenario: 共用母线模式整理
- **WHEN** 连接方式为「共用母线」并执行自动整理
- **THEN** 主干沿水平方向排列，猜你想问作为独立条目占据父卡片右侧空间，连线按母线方式生成

#### Scenario: 直接分支模式整理
- **WHEN** 连接方式为「直接分支」并执行自动整理
- **THEN** 主干保持水平，fork 出的分支树整体排在父树下方，猜你想问同样参与占位，互不重叠

#### Scenario: 撤销整理
- **WHEN** 整理完成后按 Ctrl+Z
- **THEN** 所有卡片与猜你想问回到整理前的坐标

### Requirement: 撤销

系统 SHALL 支持按画布隔离的多步撤销（Ctrl+Z），撤销深度可配置且保存不影响撤销。

#### Scenario: 多步拖动撤销
- **WHEN** 用户连续拖动 3 次后按 3 次 Ctrl+Z
- **THEN** 每次撤销回退一步，直到撤销栈耗尽

#### Scenario: 新增卡片撤销
- **WHEN** 撤销「新增卡片」
- **THEN** 已回答卡片弹出确认，确认后删除；生成中的卡片先终止流式再删除；空白输入卡片直接删除

#### Scenario: 删除撤销
- **WHEN** 一次删除多张卡片/多棵子树后按 Ctrl+Z
- **THEN** 该批次完整恢复（含内容、坐标、pin），且仅能恢复最近一次删除

#### Scenario: 按画布隔离
- **WHEN** 在 A 画布操作后切到 B，再在 B 按 Ctrl+Z
- **THEN** 只撤销 B 画布的操作；切回 A 后可继续撤销 A 的操作

#### Scenario: 保存不影响撤销
- **WHEN** 执行 Ctrl+S 或触发自动保存后再按 Ctrl+Z
- **THEN** 仍可撤销此前的画布操作，深度至少 10 步（按设置）

### Requirement: 保存

系统 SHALL 支持 Ctrl+S 保存当前画布快照，并支持可配置间隔的自动保存。

#### Scenario: 手动保存
- **WHEN** 用户按 Ctrl+S
- **THEN** 当前画布的完整节点集合写入 `backend/data/saves/`，覆盖旧文件，并给出保存成功提示

#### Scenario: 自动保存
- **WHEN** 设置中的自动保存间隔为 5（默认）
- **THEN** 每隔 5 分钟自动保存当前画布；设置为 0 时不自动保存

### Requirement: 标题编辑

卡片标题 SHALL 支持双击进入编辑，提交后更新修改时间并可撤销。

#### Scenario: 编辑标题
- **WHEN** 双击卡片顶部标题
- **THEN** 标题变为输入框，Enter/失焦提交，Esc 取消；提交后卡片标题与修改时间更新
- **AND** Ctrl+Z 可撤销这次标题修改

### Requirement: 画布平移、选择与拖动

画布 SHALL 仅在指定手势下平移；卡片 SHALL 仅能通过标题区域拖动；支持 Ctrl 多选与批量删除。

#### Scenario: 平移
- **WHEN** 按住空格并左键拖动、或按住鼠标中键拖动、或在空白处按住 300ms 后拖动
- **THEN** 画布平移；其他情况下左键拖动空白不平移

#### Scenario: 长按时间可调
- **WHEN** 在设置 → 移动 中修改长按时间
- **THEN** 空白处触发平移的等待时间随之变化

#### Scenario: 直接拖动
- **WHEN** 用户在卡片顶部标题区域按住并拖动
- **THEN** 卡片与其整棵子树立即移动，无需先选中

#### Scenario: 多选拖动
- **WHEN** 已 Ctrl 选中多张卡片后拖动其中一张的标题
- **THEN** 所有选中卡片及其子树一起移动

#### Scenario: 多选删除
- **WHEN** 多选后点击浮动菜单的「删除所选」
- **THEN** 若存在未被选中的后代，先询问；确认后删除选中卡片及全部分支；取消则不删除

#### Scenario: 元卡片
- **THEN** 元卡片默认处于固定状态；解除固定后可通过标题区域拖动

### Requirement: 连线不穿过卡片

所有逻辑线 SHALL 绕过卡片矩形，不得与卡片交叉。

#### Scenario: 绕行
- **WHEN** 一条连线的最短路径穿过其它卡片
- **THEN** 连线自动从卡片上方或下方绕行，端点仍连接正确的卡片

### Requirement: 边角缩放与吸附

卡片尺寸 SHALL 通过四边与四角拖拽调整；拖动时按住 Shift SHALL 吸附对齐。

#### Scenario: 边缘与角
- **WHEN** 在卡片上/下边拖拽只改变高度，左/右边只改变宽度，四角同时改变宽高
- **THEN** 不再出现单独的两条调整线；最小尺寸仍为 280×240，无上限

#### Scenario: Shift 吸附
- **WHEN** 按住 Shift 拖动卡片
- **THEN** 位置吸附到 20px 网格，并在接近其它卡片边缘/中心线（≤8px）时自动对齐

### Requirement: 外观自定义

设置 SHALL 提供外观选项卡，支持主题色相、连线粗细/颜色、主题模式与时间制式。

#### Scenario: 主题色相
- **WHEN** 拖动色相滑条或输入 0–360 的数值
- **THEN** 强调色立即更新并持久化，默认沿用当前青色

#### Scenario: 连线样式
- **WHEN** 修改连线粗细或颜色
- **THEN** 所有逻辑线立即使用新样式并持久化

#### Scenario: 主题模式
- **WHEN** 选择「跟随系统」「浅色」或「深色」
- **THEN** 界面立即切换；跟随系统时随操作系统深浅色实时变化

#### Scenario: 时间制式
- **WHEN** 选择 12 小时制
- **THEN** 卡片修改时间显示为 `yyyy-mm-dd hh-mm AM/PM`，24 小时制不带 AM/PM

### Requirement: 笔记卡片

双击空白画布 SHALL 新建笔记卡片；笔记拥有自定义标题、正文与独立尺寸。

#### Scenario: 新建笔记
- **WHEN** 双击空白画布
- **THEN** 在该位置创建笔记卡片，可编辑标题与正文

#### Scenario: 独立尺寸
- **WHEN** 调整笔记卡片尺寸
- **THEN** 只影响该笔记；聊天卡片与其它笔记尺寸不变

#### Scenario: 笔记参与画布操作
- **THEN** 笔记可被选中、多选、删除、固定，并纳入撤销与保存；不参与自动整理，不生成连线与建议

### Requirement: 修改时间

每张卡片（聊天与笔记）SHALL 在卡片外部右下角显示最近修改时间。

#### Scenario: 时间显示
- **WHEN** 卡片内容、标题、位置或固定状态发生变化
- **THEN** 卡片下方的修改时间按设置制式更新

## 非目标（本次范围外）

- 笔记卡片内富文本/Markdown 渲染。
- 撤销栈跨会话持久化。
- 多窗口协同编辑。
- 移动端触屏手势。
