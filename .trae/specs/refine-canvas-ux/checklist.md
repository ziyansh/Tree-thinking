## 卡片尺寸
- [x] 所有卡片使用同一全局尺寸（默认 400×560），正文超出时卡片内部滚动
- [x] 拖动卡片右边缘可改宽度，最小 280px、**不设上限**
- [x] 拖动卡片下边缘可改高度，最小 240px、**不设上限**
- [x] 调整一张卡片后，当前画布其余卡片立即同步

- [x] 候选方向与输入 ghost 不受卡片尺寸影响
- [x] 拖动缩放手柄时卡片不会被移动

## 候选方向

- [x] 点击某条候选方向后，生成完整子卡片并开始流式回答
- [x] 选择一条后，同组其余候选方向与输入项立即消失
- [x] 刷新后该组仍保持隐藏（`suggestionsConsumed` 已持久化）
- [x] 点击「换一个方向」后出现新一轮候选方向，且仍只能再选一条
