# v0.1.5 画布体验与联网搜索 Spec

## Why

v0.1.4 已解决间距与自动整理，但实际使用仍暴露 4 个交互缺陷：分支输入提交后的卡片落点偏远、猜你想问长文本被省略号截断、侧边栏残留「空画布」副标题、空格/中键拖动规则不彻底。同时设置界面信息密度低、控件样式不统一、缺少数值校验；模型服务只覆盖 DeepSeek 与官方 OpenAI，尚未体现「任意 OpenAI 兼容服务」的定位，也没有联网搜索能力。

## What Changes

### Bugfix

- 分支输入框提交后的子卡片坐标不再由前端二次覆盖，统一采用后端 `next_child_position`（即与「设置 → 画布 → 卡片间距」完全一致）；直接分支的第二个子卡片落在父卡片正下方 **1 个（卡片高度 + 间距）**，不再多空一层。
- 「猜你想问」候选按钮取消省略号：宽度在 280–420px 内随内容自动扩展，超出后自动换行、高度自适应；纵向堆叠与自动整理的 ghost 占位高度使用同一套高度估算，避免重叠。
- 删除侧边栏画布条目下的「空画布」副标题（仅保留画布名称）。
- 空格键或鼠标中键按下期间，所有拖动都视为画布平移：临时禁用卡片拖动、禁用文字选中；松开后恢复「文字区域选字、空白区域拖卡片」的原有规则。

### 显示改进

- 设置界面重做：选项卡改为「模型服务 / 画布 / 外观」三个，原「保存」并入画布；弹窗放大到 1040×760（最大 92vw / 88vh），侧栏 200px。
- 选项卡内容改为「二级标题 + 设置行」结构：左侧标题与说明、右侧控件，行间浅分隔线；输入框/下拉框不独占整行。
- 有明确取值范围的数值项统一改为「滑块 + 数字输入」胶囊样式（卡片间距、双击间隔、漂移延迟、漂移距离、候选方向、正文字号、连线粗细、超时、温度）；无上限或无意义的项保留纯数字输入（自动保存、撤销步数、最大输出 tokens）。
- 主题色相改为彩虹渐变滑块：渐变条 + 圆形/竖条滑块 + 右侧数值徽标 + 一键恢复默认（173）。
- 数值输入校验：失焦时按规则修正为最接近的合法值（小数舍弃、低于最小取最小、高于最大取最大、空值还原），保存失败时在底部展示后端返回的具体原因。
- 服务商改为下拉选择（DeepSeek / OpenAI 兼容），不再使用并排按钮。
- OpenAI 相关文案改为「OpenAI 兼容」：说明可填写任意兼容 OpenAI 协议的服务（官方 OpenAI、中转、OpenRouter、Moonshot 等）；Key 输入框去掉 `sk-…` 提示；Organization / Project 仅在填写时才发送。
- 卡片标题字号在当前正文基础上再 +1px（由 +1 变为 +2）。
- fork 按钮由纯图标改为「图标 + 新建分支」文字，与「换一个方向」同一视觉层级。

### API 与功能支持

- 新增联网搜索：设置项 `web_search_enabled`（默认关闭，持久化到后端）；画布左上角「自动重排」旁新增「联网搜索」开关按钮，开启时高亮。
- 开启后，每次回答前调用 DeepSeek Search 接口（`POST {deepseek_base}/v1/tools/search`），把结果摘要注入模型上下文；SSE 推送 `sources` 事件并落库到节点 `sources` 字段。
- 卡片底部左侧展示「参考 N 篇资料 ›」入口；点击展开悬浮窗列出搜索到的网页（标题/链接/站点/时间/摘要），再次点击或按 Esc 折叠。
- 联网搜索仅 DeepSeek 服务商可用；OpenAI 兼容服务商下按钮置灰并提示不支持。搜索失败不阻断回答，仅跳过来源展示。

### 附件与输入框

- 新增附件上传：后端提供上传接口与本地文件存储，节点新增 `attachments` 字段；前端仅在「元问题卡片输入区」与「自定义方向输入框」提供上传入口（回形针按钮 + 拖拽文件到输入框）。
- 卡片左上角顶端展示附件条：文件图标 + 文件名，图片显示缩略图；超过 3 个时折叠为「附件 N ›」，悬停临时展开，点击后保持展开。
- 图片附件点击后在当前页面打开查看器：滚轮缩放、左键拖动或按住空格/中键拖动平移、Esc 退出。
- 「自定义方向」输入框聚焦后放大为多行输入面板（参考 DeepSeek 输入框：底部左侧附件按钮、右侧圆形发送按钮）。
- 附件进入模型上下文：按「根 → 当前节点」路径注入，文本附件读取正文、图片以 base64 `image_url` 发送；兄弟分支各自的附件互不可见。

## Impact

- 受影响能力：分支创建落点、候选方向展示与自动整理、画布指针手势、设置界面与设置项、节点数据模型、回答生成链路。
- 受影响代码：
  - 后端：`app/models.py`、`app/db.py`、`app/schemas.py`、`app/services/settings.py`、`app/services/llm.py`（不改调用方式）、新增 `app/services/search.py`、`app/api/nodes.py`、`app/services/context.py`（或回答前额外插入系统消息）。
  - 前端：`api/types.ts`、`api/mock.ts`、`api/sse.ts`、`api/client.ts`、`store/graphStore.ts`、`canvas/Canvas.tsx`、`canvas/CardNode.tsx`、`canvas/GhostNode.tsx`、`canvas/GhostInputNode.tsx`、`canvas/ghosts.ts`、`canvas/layout.ts`、`components/SettingsDialog.tsx`（重写布局与控件）、`components/Sidebar.tsx`、`styles/theme.css`；新增 `canvas/AttachmentComposer.tsx`（输入区附件条与拖拽）、`canvas/AttachmentBar.tsx`（卡片左上角展示与折叠）、`canvas/ImageViewer.tsx`（图片查看器）。
  - 附件后端：新增 `app/api/attachments.py`、`app/services/attachments.py`，`app/config.py` 增加 `UPLOAD_DIR`，`requirements.txt` 增加 `python-multipart`；附件保存在 `backend/data/uploads/`。

## ADDED Requirements

### Requirement: 分支卡片落点与卡片间距一致

系统 SHALL 使用后端 `next_child_position` 计算分支输入提交后的卡片坐标；前端 SHALL NOT 用另一套公式覆盖坐标。

#### Scenario: 直接分支新增第二张子卡片
- **WHEN** 某卡片已有 1 个子卡片，用户在 fork 输入框提交新问题，连接方式为「直接分支」
- **THEN** 新卡片位于父卡片正下方，与父卡片同 x，纵向距离为 1 个「卡片高度 + 卡片间距」
- **AND** 修改卡片间距设置后，新卡片落点同步变化

#### Scenario: 共用母线新增第二张子卡片
- **WHEN** 连接方式为「共用母线」，父卡片已有 1 个子卡片
- **THEN** 新卡片与主干子卡片同列（父卡片右侧一列），纵向间隔为 1 个「卡片高度 + 卡片间距」

### Requirement: 猜你想问完整显示

系统 SHALL 让候选方向按钮完整显示文本，禁止省略号截断。

#### Scenario: 候选方向文本较长
- **WHEN** 候选方向文本超过 280px 宽度
- **THEN** 按钮宽度在 280–420px 内自动扩展，超出后自动换行，按钮高度自适应
- **AND** 纵向相邻的候选方向按钮不重叠
- **AND** 自动整理为该卡片预留的 ghost 占位高度与展示高度一致

### Requirement: 全局画布拖动优先

系统 SHALL 在空格键或鼠标中键按下时，把所有拖动行为统一为画布平移。

#### Scenario: 按住空格拖动文字区域
- **WHEN** 空格键按住，用户在卡片正文或标题上按下左键拖动
- **THEN** 画布平移，不选中文字、不拖动卡片，光标为抓取样式

#### Scenario: 中键拖动卡片
- **WHEN** 用户鼠标中键在卡片上按下并拖动
- **THEN** 画布平移，卡片位置不变

#### Scenario: 未按下空格与中键
- **WHEN** 用户直接左键拖动正文文字
- **THEN** 选中文字，不拖动卡片
- **WHEN** 用户直接左键拖动卡片空白区域
- **THEN** 拖动卡片

### Requirement: 设置界面重排与控件统一

系统 SHALL 提供三个选项卡「模型服务 / 画布 / 外观」，并在每个选项卡内用二级标题分区。

#### Scenario: 打开设置
- **WHEN** 用户打开设置
- **THEN** 弹窗尺寸为 1040×760（受视口约束），左侧选项卡顺序为 模型服务 → 画布 → 外观
- **AND** 画布选项卡包含「布局」「指针」「保存」三个二级分区
- **AND** 外观选项卡包含「主题」「卡片」「连线」「时间」四个二级分区
- **AND** 每个设置行左侧为标题与说明、右侧为控件

#### Scenario: 有界数值项
- **WHEN** 用户编辑卡片间距、双击间隔、漂移延迟、漂移距离、候选方向数量、正文字号、连线粗细、请求超时、温度
- **THEN** 该行显示「滑块 + 数字输入」胶囊控件

#### Scenario: 无界数值项
- **WHEN** 用户编辑自动保存间隔、撤销步数、最大输出 tokens
- **THEN** 仅显示数字输入框，不显示滑块

#### Scenario: 主题色相
- **WHEN** 用户查看主题色相设置
- **THEN** 显示彩虹渐变滑块、当前数值徽标与恢复默认按钮，拖动时实时预览色相

#### Scenario: 数值非法
- **WHEN** 用户在整数项输入 `3.5`
- **THEN** 失焦后修正为 `3`
- **WHEN** 输入值大于允许最大值或小于最小值
- **THEN** 失焦后修正为对应边界值
- **WHEN** 输入为空
- **THEN** 失焦后还原为修改前的值

#### Scenario: 保存失败
- **WHEN** 后端拒绝保存并返回具体原因
- **THEN** 设置底部显示该原因（如「接口地址需以 http:// 或 https:// 开头」），表单内容保留

### Requirement: 服务商与 OpenAI 兼容

系统 SHALL 以「OpenAI 兼容」定位第二个服务商，兼容任意 OpenAI 协议服务。

#### Scenario: 选择服务商
- **WHEN** 用户展开服务商下拉
- **THEN** 可选项为「DeepSeek」「OpenAI 兼容」，当前值回显正确

#### Scenario: 配置第三方兼容服务
- **WHEN** 用户选择「OpenAI 兼容」，填写第三方 base URL、Key 与模型名
- **THEN** 请求只发送已填写的参数，组织/项目为空时不发送
- **AND** Key 输入框提示文案不出现 `sk-` 前缀

### Requirement: 联网搜索

系统 SHALL 支持在回答前调用 DeepSeek Search 接口，并展示搜索来源。

#### Scenario: 开启联网搜索
- **WHEN** 用户在画布左上角点击「联网搜索」
- **THEN** 按钮进入高亮启用态，设置持久化到后端；再次点击关闭

#### Scenario: 联网回答
- **WHEN** 联网搜索开启且服务商为 DeepSeek，用户提交问题
- **THEN** 后端先调用 Search 接口，将结果摘要注入上下文后流式回答
- **AND** 前端收到 `sources` 事件并把来源保存到节点
- **AND** 卡片底部左侧出现「参考 N 篇资料」入口

#### Scenario: 查看搜索来源
- **WHEN** 用户点击「参考 N 篇资料」
- **THEN** 展开悬浮窗，逐条显示标题（可点击打开）、站点、时间与摘要
- **WHEN** 用户再次点击该入口或按 Esc
- **THEN** 悬浮窗折叠

#### Scenario: 搜索失败
- **WHEN** Search 接口报错、超时或返回空结果
- **THEN** 回答照常进行，不显示来源入口，仅记录后端日志

#### Scenario: 服务商不支持
- **WHEN** 当前服务商为「OpenAI 兼容」
- **THEN** 「联网搜索」按钮置灰，提示仅 DeepSeek 支持

### Requirement: 卡片文案与型号

系统 SHALL 将卡片标题字号提高 1px，并为 fork 入口增加文字说明。

#### Scenario: 查看卡片底部
- **WHEN** 卡片回答完成
- **THEN** 底部右侧显示「换一个方向」与「新建分支」（图标 + 文字）
- **AND** 卡片标题字号为 `var(--card-font-size) + 2px`

### Requirement: 附件上传与展示

系统 SHALL 支持在「元问题卡片输入区」与「自定义方向输入框」上传附件，并在卡片左上角顶端展示。

#### Scenario: 通过附件按钮上传
- **WHEN** 用户点击输入区的回形针按钮并选择一个或多个文件
- **THEN** 文件上传到后端本地存储，输入区出现附件条（图片显示缩略图，其它显示类型图标与文件名）
- **AND** 提交问题后，附件展示在结果卡片左上角顶端

#### Scenario: 拖拽上传
- **WHEN** 用户把系统文件拖入输入区
- **THEN** 与点击上传一致，拖入过程中输入区显示高亮反馈

#### Scenario: 附件过多折叠
- **WHEN** 卡片附件数量超过 3 个
- **THEN** 左上角只显示一个「附件 N ›」入口
- **WHEN** 鼠标悬停该入口
- **THEN** 临时展开全部附件
- **WHEN** 点击该入口
- **THEN** 保持展开，再次点击后收起

#### Scenario: 图片附件查看
- **WHEN** 用户点击图片附件缩略图
- **THEN** 前端打开全屏图片查看器
- **AND** 滚轮缩放，左键拖动或按住空格/中键拖动平移图片位置，Esc 关闭

#### Scenario: 附件上下文独立
- **WHEN** A、B 同为 C 的子卡片且各自上传了不同附件
- **THEN** A 的回答只读取「根 → A」路径上的附件，B 只读取「根 → B」路径上的附件，互不可见

#### Scenario: 附件进入模型上下文
- **WHEN** 回答某节点且其路径上存在附件
- **THEN** 文本附件以 UTF-8 读取并拼入对应 user 消息（单文件最多 20000 字符、单次请求合计最多 60000 字符）
- **AND** 图片附件以 base64 data URL 的 `image_url` 内容块加入对应 user 消息（`detail: low`，支持 JPEG/PNG/GIF/WebP）
- **AND** 无法读取或类型不支持的附件跳过并记录日志，不阻断回答

#### Scenario: 上传入口限制
- **WHEN** 用户在其它卡片或 fork 分支输入条上操作
- **THEN** 不提供附件上传入口

### Requirement: 自定义方向输入框聚焦放大

系统 SHALL 在「自定义方向」输入框获得焦点时放大为多行输入面板。

#### Scenario: 聚焦展开
- **WHEN** 用户点击「自定义方向」输入框
- **THEN** 输入框由 280px 单行扩展为约 460px 宽、最少 120px 高的面板
- **AND** 底部出现左侧附件按钮与右侧圆形发送按钮

#### Scenario: 失焦收起
- **WHEN** 输入框失去焦点且内容为空
- **THEN** 恢复为 280px 单行输入条

#### Scenario: 提交后重置
- **WHEN** 用户提交问题
- **THEN** 文本与本次选择的附件清空，输入框仍可继续使用

## MODIFIED Requirements

### Requirement: 设置项整合

原「保存」选项卡的自动保存间隔、撤销步数并入「画布」选项卡的「保存」分区；原「指针」设置仍位于「画布」的「指针」分区。

### Requirement: 侧边栏画布列表

画布列表项只显示画布名称与悬浮操作按钮，不再显示根问题摘要或「空画布」占位。

## REMOVED Requirements

### Requirement: 侧边栏画布摘要
**Reason**: 摘要长期显示「空画布」，与实际对话状态不符且占用垂直空间。
**Migration**: 直接删除摘要行，历史数据无需迁移。

## 假设与待确认

1. 「联网搜索」开关作为全局持久化设置保存（`app_settings.web_search_enabled`），对所有画布生效。
2. 联网搜索仅 DeepSeek 服务商可用；OpenAI 兼容服务商只能关闭该功能。
3. 来源展示使用 Search 接口返回的 `summary`，不调用 Fetch 抓取全文，控制 token 与延迟。
4. 官方 Search 接口只接受单一 query，无法得知实际关键词数量，因此入口文案显示「参考 N 篇资料」，不显示「搜索 N 个关键词」。
5. 「修改 OpenAI 的支持」按「文案 + 兼容性适配」理解：重命名为「OpenAI 兼容」、去掉 `sk-` 提示、官方专属参数保持默认不发送。
6. 附件限制：单文件最大 20MB、单条消息最多 10 个；图片以 base64 内联发送，不使用 Files API；未提交或被替换的附件文件不做自动清理。
7. 附件仅在上传输入区提供移除操作；卡片左上角的展示区只读。
8. 模型若为不支持图像输入的 OpenAI 兼容服务，携带图片的请求会由该服务自行报错，错误按现有链路展示在卡片上。
