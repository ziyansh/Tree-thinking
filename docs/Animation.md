# 动画设计原则

1.目的优先，隐退式动效：所有动画都要有信息作用（反馈手势、解释层级、交代对象变换），纯粹好看的动画不被鼓励；最好的动画让人不察觉，但拿掉就会觉得别扭，内容永远第一位￼￼￼。

2. 流体交互、可中断：动画不是预渲染片段，以弹簧、动量、橡皮筋阻力为基础；任何运动中的元素随时可以被手势抓住、改方向、取消，继承手指速度，适配人随时变化的意图。

3. 空间与对象连续：维持一套连贯虚拟空间；同一个视觉主体（图标、灵动岛、窗口）在转场里保持身份；转场方向本身就是导航语义；visionOS、折叠屏进一步延续空间连贯性。

4. 感知物理，而非写实物理：优先人脑直觉，不是严格物理公式；追求连续速度，没有突兀闪现、硬跳；同时和 Taptic 触觉、音效同步，形成多感官质感。

5. 跨平台统一，节奏克制：iPhone、Mac、Watch、Vision Pro 共用同一套运动语法与时长基准；高频交互短促、轻，重大转场才舒展。

6. 强制无障碍约束：必须支持减弱动态效果，关键信息不能只靠动画传递，照顾前庭敏感人群。

7. 运动即是材质响应（Liquid Glass）

# **在什么地方、什么时候使用动画**

核心判断标准：**只有当动画能帮助用户理解变化、建立因果、反馈操作时，才启用动画；无信息价值的场景，不加动画。**

## ✅ 会设置动画的场景（什么时候 / 哪里）

### 1. 用户进行手势 / 点击操作时：即时反馈

>

> 目的：告诉系统 “收到你的操作了”，消除延迟感

- 点击按钮、开关、控件、长按菜单、拖拽滑块

- 滑动页面、列表滚动（惯性滚动 + 橡皮筋回弹）

- 拖动窗口、控件、卡片（实时跟随手指的弹簧运动）

- 手势导航：侧滑返回、上滑回主页、上滑停留多任务

### 2. **界面层级发生变化（页面 / 浮层出现、消失）**

>

> 目的：用运动交代层级关系，告诉用户新界面从哪来、和当前页面是什么关系

- 底部弹出模态弹窗、菜单（从下往上动画 = 临时覆盖层）

- 页面左右推入（同级页面跳转）

- 窗口打开 / 关闭、App 启动与退出（图标缩放连续转场，对象连续性）

- 通知弹出、收起；控制面板、通知中心拉出收回

### 3. **同一个对象发生形态转移 / 变形（对象连续性）**

>

> 目的：让用户识别 “这还是同一个东西，只是变了样子”

- 灵动岛：通话、音乐、计时器状态变化时的伸缩、分裂、合并

- 照片缩略图点开放大，关闭缩回去

- visionOS 窗口拖拽、缩放、移动、悬浮

- 折叠屏设备窗口展开 / 折叠的连续形变

- SF Symbol 图标状态切换（如 wifi、电量、加载状态符号变化）

### 4. **状态改变，需要提示用户**

>

> 目的：温和提示状态变更，不打断

- 加载进度、刷新动画

- 开关开启 / 关闭、勾选框选中

- 警告、确认提示的淡入

- Apple Watch 界面切换、数字表冠旋转联动动画

### 5. **建立空间深度，辅助感知**

>

> 目的：区分图层远近，营造空间感

- 锁屏、主屏幕的视差（壁纸随手机倾斜轻微移动）

- visionOS：窗口景深、靠近 / 远离时光影变化

- 弹窗浮层轻微抬升动画

### 6. **多感官联动场景（动画 + 触觉 Taptic）**

- 滚动触底回弹、长按震动、拖拽释放弹簧回弹：视觉动画和触觉同步触发

## ❌ **苹果不会设置动画的场景**

1. 纯装饰、没有信息含义的持续浮动、闪烁、粒子特效

2. 静态文字信息单纯出现，没有层级 / 状态变化

3. 会引发眩晕、强烈大幅度旋转 / 快速平移（除非必要）

4. 动画会阻塞操作：**动画不能强制用户等播放完**（必须可中断）

5. 开启「减弱动态效果」后，复杂弹簧、视差动画会降级为简单淡入淡出

## ⏱️ 时机规则（什么时候触发，什么时候不触发）

1. **用户主动操作才触发动画；自动变化尽量克制**

用户点 / 滑 / 拖 → 触发动画；

页面自动变化（自动弹窗、自动轮播）尽量少用动态。

2. **高频操作，动画短而轻；低频重大转场，动画更长**

点开关：100–200ms；App 打开、照片放大：300–500ms。

3. **动画起点和用户手势同步，不延迟**，优先保证感知响应速度。

4. **任何正在播放的交互动画，随时可被手势打断**
