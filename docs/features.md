# 功能详解

本文是 [README](../readme.md) 的补充说明，完整列出当前版本的功能与行为细节。服务器部署见 [deploy.md](deploy.md)，开发约定见 [development.md](development.md)。

## 画布

- **无限画布，从左往右生长**：每一轮追问都在右侧生成新卡片；画布可以无限平移与缩放。
- **平移**：空格 + 左键拖动、鼠标中键拖动，或在空白处按住拖动（漂移延迟与距离可配）。按住空格时，即使指针落在卡片文字、标题、附件或未聚焦的输入框上，拖动也一律平移画布。
- **缩放**：滚轮在卡片内可滚动区域（回答正文、思考过程、笔记正文）滚动内容，在画布其它区域缩放；按住空格时滚轮始终缩放画布。
- **触摸板（实验性）**：设置中把指针设备切到「触摸板」后，双指滑动平移画布、双指捏合缩放画布；按住空格时双指滑动同样平移。
- **卡片尺寸**：聊天卡片共用一套全局尺寸，四边与四角都可拖拽调整（最小 280×240）；笔记卡片拥有独立尺寸。字号变大时卡片会自动放大。
- **拖动与固定**：卡片任意空白区域都可以拖动；固定后的卡片不能直接拖动（元卡片默认固定），拖动会带动整棵子树。
- **多选与吸附**：Ctrl 多选、批量删除；Shift 吸附 20px 网格与相邻卡片。
- **撤销与保存**：每个画布独立的多步撤销（Ctrl+Z，步数可配，包含卡片尺寸修改）；Ctrl+S 手动保存，也可按设置的间隔自动保存；保存不会清空撤销记录。
- **自动整理**：元卡片保持原位，主干链始终在一条水平线上；直接分支落在父卡片同列下方，共用母线的分支头落在右侧下一列并共享母线；行列间距可调。
- **动态层级**：点击、拖动或聚焦卡片视为状态更新，卡片会压在笔记卡片之上；正在流式回答的卡片同样置顶。未获焦时，笔记高于「猜你想问」，普通聊天卡片在最下层。连线始终渲染在卡片下方。
- **画布样式**：纯色或点状背景；可开启拖动惯性并调整系数。

## 搜索

- **画布内搜索**：`Ctrl/Cmd + F` 在画布顶部打开毛玻璃搜索面板，只检索当前画布的卡片标题与正文（含笔记）。结果显示命中附近的片段并高亮关键词。单击结果时镜头直接对准卡片内命中的关键词（保持当前缩放），命中内容同时高亮并平滑闪烁约 3.5 秒，随后保持高亮底色提示位置；正文命中还会把卡片内部滚动到命中处。短时间再次点击同一条结果（按设置中的双击间隔判定）才把缩放恢复到 100%，当前已放大时保持不变。面板可拖动右下角调整大小，尺寸保存在浏览器本地，下次打开沿用。
- **全局搜索**：左侧侧边栏顶部搜索框跨所有画布检索画布名、卡片标题与正文。结果浮层铺满侧边栏宽度，标注所属画布与字段类型；点击结果依次切换画布、移动镜头、按视口适配到合适缩放，并高亮闪烁命中内容，闪烁结束后恢复普通文本，不在卡片上保留高亮。
- **匹配范围**：不区分大小写的子串匹配；服务器模式下只返回当前账号的画布，画布内搜索还会额外限定在正在打开的画布。单次最多返回 60 条，超出时标注「已截断」。

## 对话卡片

- **一问一答**：每张卡片保存一个问题与一条回答；回答以 Markdown 渲染，支持表格、代码块与数学公式，内容超高时在卡片内部滚动。
- **候选方向**：回答完成后，右侧给出候选追问（默认 3 条，可配 2–6）与 1 条「自定义方向」。同一轮只能选一条，选中后整组隐藏；「换一个方向」会重新生成一轮。
- **分支输入**：卡片下方可展开与卡片同宽的输入条，长文本自动换行增高，回车提交。
- **上下文隔离**：请求只包含「根 → 当前节点」路径上的问答，兄弟分支之间互不可见。
- **思考过程**：开启思考模式后，卡片的「思考过程」默认折叠，点击展开；思考内容不会进入后续上下文。
- **回答操作**：停止生成、从断点续写、重新生成、复制问题与回答；空回答时卡片中央提供「重新提交」。
- **标题**：双击标题即可编辑，Enter 或失焦提交，Esc 取消；使用 DeepSeek 时，根卡片首次回答后会自动生成画布标题，手动改名后不再覆盖。
- **修改时间**：聊天与笔记卡片外部右下角显示最后修改时间，支持 12/24 小时制。

## 笔记与连线

- **创建笔记**：双击空白画布即可创建；标题与正文双击进入编辑（单击让位给拖拽与选中），正文编辑时按 Tab 插入 4 个空格。
- **笔记尺寸**：拖动四边或四角调整，独立于聊天卡片。
- **笔记连接线**：回答卡片底部与笔记标题行各有一个连接点，从任一端拖出即可建立无方向关联；指针落在目标卡片矩形内或连接点附近会自动吸附。
- **连线外观**：曲线或直角线、粗细、颜色可调；悬停连线变强调色，按 Delete 删除。
- **释放动作**：从回答卡片出发未命中笔记时，可按设置决定「不动作 / 按住 Shift 新建空白笔记并连接 / 直接新建空白笔记并连接」。

## 输入与附件

- **四个输入位置**：元问题卡片、自定义方向输入、分支输入条、卡片顶部「我的提问」抽屉，功能一致。
- **附件上传**：点击回形针或直接拖拽文件；支持图片、文本、PDF、视频、音频与其他文件。单文件上限 20MB，单节点最多 10 个。
- **附件标签**：卡片左上角显示文件图标与文件名；超过 3 个折叠为「附件 N」；单击条目打开原始文件，PDF 与图片在浏览器内直接预览。
- **粘贴**：从文件管理器粘贴文件会作为附件上传；超过 2000 字符的纯文本会自动转成 `.txt` 附件。
- **PDF 提示**：任一 PDF 超过 30 页或合计超过 30 页时，提交按钮左侧提示「pdf页数过多，费用可能失控」；超过 100 页时提示可能超出模型上下文。
- **文档解析**：DeepSeek 会把 PDF / Office 文档上传到 Files API 解析；火山方舟会把图片 / 视频 / 音频 / PDF 上传到方舟 Files API；OpenAI 兼容保持图片与文本注入。
- **链接识别**：输入或粘贴网址时，链接会从文本中抽离成输入框下方的编号胶囊，输入框只保留正文。单击胶囊在新标签打开，双击可内联编辑（Enter 保存、Esc 取消），点 × 移除。提交时链接按胶囊编号顺序拼回问题末尾，最多 10 个。

## 模型与联网搜索

- **服务商**：DeepSeek（默认）、火山方舟、OpenAI 兼容，三者各自保存 Key、接口地址与模型。
- **DeepSeek**：支持 `deepseek-flash` / `deepseek-v4-pro`；可开关思考模式，强制搜索时注入的资料条数可设为 1–50（默认 50）。
- **火山方舟**：可填写 API Key、接口地址与模型名，支持流式回答、深度思考与智能联网搜索；模型候选来自方舟 Models 接口，只列出可输出文本的模型。
- **OpenAI 兼容**：支持任意兼容 OpenAI 协议的服务，可配置组织 / 项目、温度、最大输出、推理强度与请求超时。
- **联网搜索**：画布左上角与输入区各有一个开关；开启后先检索再回答，卡片左下角显示「参考 N 篇资料」，点开是从卡片底部升起的来源抽屉。
- **引用角标**：DeepSeek 回答正文中的 `[n]` 会渲染成可点击的来源角标；火山方舟只展示来源列表，不插入角标。
- **会话标题**：仅 DeepSeek 在根卡片首次回答时生成画布标题。

## 设置

- **三个选项卡**：模型服务 / 画布 / 外观，保存后立即生效，无需重启。
- **交互方式**：分组标题 + 左侧说明、右侧控件；有界数值使用「滑块 + 数字输入」，失焦自动修正。
- **恢复默认设置**：左下角按钮可恢复全部设置，已保存的 API Key 保留；服务器模式只影响当前账号。
- **主要设置项**：
  - 模型服务：服务商、API Key、接口地址、模型、思考模式、建议数量、搜索方式与上限；
  - 画布：连接方式、卡片间距、拖动惯性、画布样式、触摸板逻辑、双击间隔、指针漂移延迟与距离、自动保存间隔、撤销步数；
  - 外观：主题模式、字号、主题色相、连线粗细与颜色、笔记连线样式 / 粗细 / 颜色 / 释放动作、时间制式。

## 账号与数据

- **本地模式**：默认 `APP_MODE=local`，单人使用、无需登录；设置写入本地数据库，模型 Key 可由页面设置或 `backend/.env` 兜底。
- **服务器模式**：`APP_MODE=server` 时需注册登录，画布、节点、附件、设置与 API Key 按账号隔离；新账号从全默认设置开始，不含任何 Key，也不会继承 `.env` 中的模型 Key。
- **账号规则**：用户名 3–32 位字母、数字或下划线且不可重复；密码 4–12 位；注册页在输入框失焦后即时校验。
- **密钥保护**：模型 Key 加密存储在后端数据库，接口只返回脱敏值（如 `sk-••••7890`），不写入浏览器缓存。
- **持久化**：画布、节点、坐标、视口、笔记与连线保存在 SQLite；刷新页面完整还原。
- **导出与导入**：画布可导出为 JSON 文件并重新导入，导出包含节点、视口与笔记连接。
- **数据外发边界**：回答、联网搜索与文档解析会把当前分支的问答与所选附件发送给当前服务商；不会发送其他账号的数据、未选中服务商的 Key 与配置。完整清单见 [deploy.md](deploy.md) 的「出站网络与数据外发」一节。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `Space` + 左键拖动 | 平移画布 |
| 鼠标中键拖动 | 平移画布 |
| 滚轮 | 卡片可滚动区域滚动内容，其它区域缩放画布；按住 Space 时缩放画布 |
| `Esc` | 按「最后打开的先关闭」的顺序关闭浮层 / 抽屉 |
| `Tab`（仅笔记正文编辑中） | 插入 4 个空格 |
| `Delete` | 删除当前选中的卡片（元问题卡片除外） |
| `Ctrl/Cmd + F` | 打开 / 聚焦画布内搜索 |
| `Ctrl/Cmd + Z` | 撤销当前画布的上一步操作 |
| `Ctrl/Cmd + S` | 保存当前画布 |
