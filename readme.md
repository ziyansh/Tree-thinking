# 树状对话画布（Tree Thinking）

> 当前版本：**0.3.13** ｜ [English README](readme_en.md)
>
> **WIP**：本项目仍在开发中，功能与界面可能随时调整，不代表最终品质。
>
> **平台**：Windows 10/11 为主；macOS 为理论支持；Linux 仅验证过服务器部署。

把线性聊天变成一棵可以无限延伸的思维树：每一次问答都是画布上的一张卡片，卡片右侧长出候选追问，点选任意一个就沿着该方向继续。所有分支独立保存上下文，可以随时回头比较不同思路。

## 特色功能

- **对话长成一张地图**：每张卡片只装一问一答，回答后给出几个下一步方向；选一个就在当前上下文里继续，也可以自己另起一条。分支各走各的，回头看时不必在长聊天记录里翻找。
- **想法可以直接写在画布上**：双击空白处创建笔记，拖到任意位置，再用一条弱连接线挂到某张回答卡片上。笔记不参与对话，也不占模型上下文。
- **带着材料提问**：图片、PDF、文本、视频、音频都可以拖进输入框。多个附件自动折叠，点开就能看到原文件；PDF 页数过多时会提前提醒费用与上下文风险。
- **思考与联网都在卡片里完成**：思考过程折叠在卡片中，需要时展开；开启联网搜索后，回答左下角会列出参考来源，点开是从卡片底部升起的资料抽屉。
- **本地与在线，两种用法**：默认本地单人免登录；切换服务器模式后支持多账号注册登录，画布、附件、设置与密钥彼此隔离。
- **常用操作不用离开画布**：拖动、缩放、固定、多选、撤销、自动保存、导出导入都在画布上完成；层级会跟着焦点自动整理。

完整功能与行为细节见 [docs/features.md](docs/features.md)。

## 快速开始


### 安装前置依赖

运行本项目需要三样东西，缺一不可：

| 依赖 | 版本要求 | 用途 | 下载地址 |
| --- | --- | --- | --- |
| Git | 任意较新版本 | 拉取源码 | <https://git-scm.com/downloads> |
| Python | 3.10 或更高 | 运行后端 | <https://www.python.org/downloads/> |
| Node.js | 20.19 或更高（含 npm） | 运行与构建前端 | <https://nodejs.org/> |

Windows 安装时注意：

- **Python**：安装向导第一页勾选「Add python.exe to PATH」，否则命令行里找不到 `python`；
- **Node.js**：下载 LTS 版本即可，安装包会同时装好 `npm`；
- **Git**：安装包默认选项即可，安装后可以在开始菜单打开 Git Bash。

安装完成后重新打开一个命令行窗口，确认版本：

```powershell
git --version
python --version
node --version
npm --version
```

macOS 可以使用 Homebrew 安装（`brew install git python node`，未安装 Homebrew 时先访问 <https://brew.sh>）。Linux 用包管理器安装 Git、Python 3 与 `python3-venv`，Node.js 建议通过 NodeSource 或 nvm 安装 20.19 以上版本。

### 获取源码

打开命令行，克隆仓库并进入项目目录：

```bash
git clone https://github.com/ziyansh/Tree-thinking.git
cd Tree-thinking
```

后续所有命令都在这个 `Tree-thinking` 目录中执行。如果是下载压缩包，解压后进入解压出的目录即可。

### 服务器部署

需要部署到服务器供多人使用？先按上一节克隆代码，再阅读[服务器部署指南](docs/deploy.md)。文档包含服务器依赖安装、环境变量、systemd、Nginx、HTTPS、备份与升级步骤。

### Windows

Windows 10/11 是主要支持平台。

#### 一键启动

在文件资源管理器中打开克隆后的 `Tree-thinking` 目录，双击 `start.bat`。脚本会自动：

1. 检查 Python 与 Node.js；
2. 创建 `backend/.venv` 并安装后端依赖；
3. 缺少 `backend/.env` 时从 `.env.example` 复制一份；
4. 安装前端依赖；
5. 启动后端与前端，并在浏览器打开 `http://localhost:5173`。

启动后会保留两个命令行窗口，关闭窗口即停止对应服务。首次运行需要下载依赖，耗时取决于网络。

#### 手动启动

打开两个 PowerShell 窗口，都先进入项目目录：

```powershell
cd Tree-thinking
```

**第一个窗口：后端**

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

**第二个窗口：前端**

```powershell
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。Vite 已把 `/api` 代理到 `http://127.0.0.1:8000`。

### macOS、Linux

macOS 为理论支持：代码与依赖是跨平台的，但没有经过完整实测。Linux 目前只验证过服务器部署，桌面环境下的本地使用尚未测试。

**第二个终端：前端**


打开 `http://localhost:5173`。服务器部署请按 [docs/deploy.md](docs/deploy.md) 操作。

### 从源码部署

开发模式（`npm run dev`）不适合直接对外提供服务。克隆代码并安装好依赖后：

1. 后端用虚拟环境运行 `uvicorn app.main:app`，不要带 `--reload`，并用 systemd 等进程管理器托管；
2. 前端执行 `npm run build`，把生成的 `frontend/dist` 交给 Nginx 或其它静态服务器托管；
3. 把 `/api` 反向代理到后端端口，并配置 HTTPS。

完整步骤、环境变量、Nginx 配置、备份与升级流程见[服务器部署指南](docs/deploy.md)。

## 使用指南

1. **写下元问题**：首次进入会自动创建画布，根卡片处于输入状态。
2. **等待回答**：回答逐字出现；开启思考模式时，可展开「思考过程」。
3. **选择下一步**：
   - 点候选卡片，沿该方向生成完整对话卡片；
   - 在卡片下方的输入条里写自己的问题；
   - 「换一个方向」重新给出一轮候选。
4. **比较分支**：任意卡片都能继续分叉，不同分支的后续内容互不影响。
5. **管理画布**：左侧侧边栏可以新建、切换、重命名、删除画布。
6. **做笔记**：双击空白处创建笔记，双击标题或正文进入编辑；拖动边缘调整尺寸。
7. **调整设置**：左下角「设置」包含模型服务、画布与外观三个选项卡，保存后立即生效。
8. **撤销、保存与删除**：`Ctrl+Z` 撤销、`Ctrl+S` 保存、`Delete` 删除选中的卡片（元问题卡片除外）。

更多细节见 [docs/features.md](docs/features.md)。

## 常见问题

**卡片提示「未配置 API Key」怎么办？**

打开左下角「设置」填写 Key 并保存，无需重启。

**端口被占用怎么办？**

后端可改用 `--port 8001`，同时修改 `frontend/vite.config.ts` 里的代理地址。

**想清空全部数据怎么办？**

停止后端，删除 `backend/data/app.db`，再重新启动。

**回答很慢或没有思考过程怎么办？**

检查「设置 → 模型服务」中的思考模式与模型名。

**如何切换主题？**

在「设置 → 外观」选择跟随系统 / 浅色 / 深色，并可调整主题色相与连线颜色。

**只想修改默认值怎么办？**

编辑 `backend/.env` 后重启后端；页面里保存过的设置优先级更高。

**触摸板手势为什么没有生效？**

触摸板目前是实验性支持，需要在「设置 → 画布 → 指针 → 触摸板逻辑」中切换为「触摸板（实验性）」。切换后双指滑动平移画布、双指捏合缩放画布，按住空格时双指滑动同样平移。该功能尚未在各类设备上充分实测，不同系统的触控板驱动表现可能不同；如果手势异常，切回「鼠标」即可恢复标准滚轮行为，但对触摸板的兼容性较差。

**Windows 控制台日志出现 `[32mINFO[0m` 之类的乱码怎么办？**

旧版控制台不解析 ANSI 颜色码。可在 Windows Terminal 中运行 `start.bat`，或执行 `reg add "HKCU\Console" /v VirtualTerminalLevel /t REG_DWORD /d 1 /f` 后重开窗口。

**`.env` 被 Git 忽略正常吗？**

这是预期行为。提交前请确认没有把 `backend/.env`、真实 Key 或数据库文件加入暂存区。

## 项目结构

```
Tree_thinking/
├─ start.bat                  # Windows 一键启动
├─ readme.md / readme_en.md   # 中文 / 英文说明
├─ LICENSE / NOTICE           # Apache 2.0 许可与版权、商标声明
├─ docs/
│  ├─ features.md / features_en.md   # 功能详解
│  ├─ deploy.md / deploy_en.md       # 服务器部署指南
│  └─ development.md                 # 开发约定
├─ backend/
│  ├─ .venv/                  # 独立虚拟环境（不入库）
│  ├─ requirements.txt
│  ├─ app/
│  │  ├─ main.py              # FastAPI 入口
│  │  ├─ db.py, models.py, schemas.py, config.py
│  │  ├─ api/                 # auth / projects / nodes / links / attachments / models / settings
│  │  └─ services/            # auth / llm / context / attachments / citations / suggestions / search / naming / settings / graph / urls
│  └─ tests/                  # pytest 单元与接口测试
└─ frontend/
   ├─ vite.config.ts          # 5173 + /api 代理
   └─ src/
      ├─ api/                 # client / sse / mock / types
      ├─ canvas/              # Canvas / CardNode / 附件 / 笔记连线 / 布局
      ├─ components/          # Sidebar / SettingsDialog / AuthPage
      ├─ lib/                 # escapeStack / theme / time / urlChips 等工具
      ├─ store/               # Zustand 图状态
      └─ styles/theme.css     # 主题令牌（浅色/深色）
```

技术栈：前端 React 19 + TypeScript + Vite 8 + @xyflow/react 12 + Zustand 5 + Tailwind CSS v4；后端 FastAPI + SQLAlchemy 2 + SQLite；流式回答使用 SSE。
