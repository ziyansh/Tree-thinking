# 树状对话画布（Tree Thinking）

> 当前版本：**0.2.2** ｜ [English README](readme_en.md)

把线性聊天变成一棵可以无限延伸的思维树：每一次问答都是画布上的一张卡片，卡片右侧长出候选追问箭头，点选任意箭头就沿着该方向生成新卡片。所有分支独立保存上下文，随时可以回头比较不同思路。

## 功能特性

- **无限画布，从左到右**：基于 React Flow，支持空格 + 左键、中键，或在空白处按住拖动（漂移延迟/距离可配）平移；按住空格时即使在卡片文字、标题、附件或未聚焦的输入框上拖动也一律平移画布。滚轮行为可在「设置 → 画布 → 指针 → 滚轮逻辑」中切换：悬停卡片时滚动内容或缩放画布；按住空格时仍保持缩放。
- **卡片式问答**：每张卡片 = 一问一答；回答以 Markdown 渲染，超高时卡片内部滚动，不撑坏画布。
- **卡片文字可选中**：标题、Markdown 正文、思考过程与输入框都可以直接拖选文字，选字不会移动卡片；按住空格时优先平移画布、不选中文字；笔记标题与正文需双击进入编辑后才能选中；选中高亮使用柔和的主题色。
- **卡片尺寸与笔记**：聊天气泡使用全局统一尺寸，四边/四角均可拖拽调整（最小 280×240）；笔记卡片拥有独立尺寸；双击空白画布即可创建笔记，标题与正文需双击进入编辑（单击让位给拖拽与选中），正文编辑时按 Tab 插入 4 个空格。
- **候选方向（紧凑 + 单选）**：回答完成后，右侧以紧凑纵向排列给出候选卡片（默认 3、可配 2–6）与 1 条自定义输入；同一轮只能选一条，选中后整组隐藏，点「换一个方向」重新给出一轮；候选卡片与分支输入条分层显示，互不遮挡。
- **分支输入与上下文隔离**：分支入口为卡片下方同宽输入框，长文本会自动换行增高，回车即生成新卡片；请求上下文只包含「根 → 当前节点」路径上的问答，兄弟分支互不可见。
- **分支连线**：主链保持左→右；直接分支从父卡片上/下边中点连到子卡片；共用母线让同一父卡片的全部非主干分支共用一条母线，连线会自动绕开卡片。
- **自动整理**：元卡片保持当前位置，主干链始终在一条水平直线上；直接分支的分支头落在父卡片同列下方，共用母线的分支头落在右侧下一列并共享同一条母线；行列间距可在「设置 → 画布 → 卡片间距」统一调整。
- **拖动、固定与多选**：卡片任意空白区域均可拖动，文字与按钮不会误触发拖动；拖动时显示抓取光标。固定后不可直接拖动（元卡片默认固定），拖动会带动整棵子树；Ctrl 多选、批量删除，Shift 吸附 20px 网格与相邻卡片。
- **标题编辑**：双击卡片标题即可编辑（间隔可在设置中调整），Enter 或失焦提交，Esc 取消。
- **撤销与保存**：每个画布独立的多步撤销（Ctrl+Z，步数可配，包含卡片尺寸的修改），Ctrl+S 手动保存并支持可配自动保存，保存不影响撤销；选中卡片后按 `Delete` 可快速删除。
- **多画布管理**：左侧可折叠侧边栏（240px / 48px）用于新建、切换、重命名、删除画布；每个画布有且仅有一个元问题；首次对话完成后会用模型自动生成画布标题，用户手动改名后不再覆盖。
- **应用内设置**：左下角「设置」打开悬浮窗，含模型服务 / 画布 / 外观三个选项卡（保存选项并入画布）；分组标题下每行左侧说明、右侧控件，有界数值使用「滑块 + 数字输入」，**保存后立即生效，无需重启服务**。
- **多服务商接入**：服务商为下拉选择（DeepSeek / OpenAI 兼容），后者支持任意兼容 OpenAI 协议的服务。DeepSeek 支持 `deepseek-flash` / `deepseek-v4-pro`；OpenAI 兼容可配置组织/项目、温度、最大输出、推理强度与请求超时，也可填写中转地址。
- **联网搜索**：画布左上角「自动重排」旁有「联网搜索」开关（仅 DeepSeek），卡片输入区的附件按钮旁也有同步的快捷开关；开启后回答前调用 DeepSeek Search 并注入资料摘要，资料条数可在「设置 → 模型服务 → 通用 → 模型搜索上限」调整（默认 0 表示不设限）。卡片左下角显示「参考 N 篇资料」，点击后从卡片底部升起可上下拖动的毛玻璃抽屉（默认占卡片 25% 高度，高度会记忆并应用到所有卡片），抽屉内按序号列出网页标题并链接到原文；回答正文中的 `[n]` 引用会渲染成可点击的序号角标；只点击入口箭头或按 Esc 才收起。
- **附件问答**：元问题输入区与「自定义方向」输入框支持点击或拖拽上传任意文件；卡片左上角统一显示文件图标与文件名（超过 3 个折叠为「附件 N」，点击条目在新窗口打开原始文件）。文本附件按「根 → 当前节点」路径注入上下文，兄弟分支互不可见。
- **持久化**：画布、节点、坐标、视口保存在本地 SQLite；刷新页面完整还原。
- **外观主题**：跟随系统 / 浅色 / 深色，主题色相、连线粗细与颜色可调，时间制式支持 12/24 小时；卡片正文字号可调（12–24px，默认 14），字号变大时卡片会自动放大。
- **修改时间**：聊天与笔记卡片外部右下角显示修改时间（`yyyy-mm-dd hh:mm`，12 小时制附 AM/PM），随编辑实时更新。

## 快速开始

### 环境要求

- Python 3.10+
- Node.js 18+（本项目在 Node 25 下开发验证）
- Windows 10/11 或 macOS 12+（Intel / Apple Silicon）
- Linux 也可使用 `start.sh`；当前开发环境为 Windows，macOS / Linux 尚未实机验证

### 一键启动（推荐）

**Windows**：双击仓库根目录的 `start.bat`。

**macOS**：在仓库根目录执行：

```bash
bash start.sh
# 也可以先 chmod +x start.sh，之后用 ./start.sh
```

两个脚本都会：

1. 缺少 `backend/.venv` 时自动创建并安装后端依赖；
2. 缺少 `frontend/node_modules` 时自动 `npm install`；
3. 缺少 `backend/.env` 时从 `.env.example` 复制默认配置；
4. 启动后端与前端，等待就绪后打开浏览器。macOS 版日志写入 `.runtime/`，按 `Ctrl+C` 会同时停止两个服务。

> API 配置不在启动脚本里进行：首次打开页面后，点击左下角「设置」填写 API Key，保存即生效。

> 从 Windows 迁移到 macOS（或反向）时，请先删除 `backend/.venv` 与 `frontend/node_modules`，再运行脚本，让依赖按当前平台重新安装。

### 手动启动

**Windows（PowerShell）**

```powershell
# 终端 1：后端
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --port 8000 --reload

# 终端 2：前端
cd frontend
npm install
npm run dev
```

**macOS / Linux（zsh / bash）**

```bash
# 终端 1：后端
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --port 8000 --reload

# 终端 2：前端
cd frontend
npm install
npm run dev
```

打开 `http://localhost:5173`。Vite 已把 `/api` 代理到 `http://127.0.0.1:8000`。

路径说明：数据库与上传目录默认是相对仓库根目录的 `backend/data/...`，Windows 与 macOS 相同；`DB_PATH` / `UPLOAD_DIR` 支持 `~`（如 `~/tree-thinking/app.db`），无需手写不同平台的路径分隔符。

## 配置

配置来源优先级：**页面「设置」 > `backend/.env`**。设置保存在 `backend/data/app.db`，不会写入前端产物。

| `backend/.env` 键 | 说明 | 默认值 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | DeepSeek API Key，留空则回答报错 | 空 |
| `DEEPSEEK_BASE_URL` | OpenAI 兼容接口地址 | `https://api.deepseek.com` |
| `DEEPSEEK_MODEL` | 模型名 | `deepseek-flash` |
| `THINKING_ENABLED` | 是否开启思考模式 | `true` |
| `SUGGESTION_COUNT` | 候选方向数量（2–6） | `3` |
| `DB_PATH` | SQLite 文件路径 | `backend/data/app.db` |

说明：

- 应用内「设置」可覆盖前三项与思考模式、建议数量；接口地址与模型留空会恢复 `.env` 默认值。
- API Key 只保存在后端本地；读取设置时接口只返回脱敏值（如 `sk-••••7890`）。
- Key 申请地址：<https://platform.deepseek.com/api_keys>。

## 使用指南

1. **输入元问题**：首次进入自动创建画布，根卡片处于输入态，写下你的起始问题。
2. **等待流式回答**：回答实时逐字出现；若开启思考模式，可展开「思考过程」。
3. **选择下一步**：
   - 点某张候选卡片 → 原地生成完整对话卡片并沿该方向继续；同一轮只能选一条，选中后整组候选自动隐藏；
   - 在卡片下方长条输入框中写问题并回车 → 创建自定义分支，可重复使用；
   - 「换一个方向」会重新给出一轮候选；卡片底部的分支按钮可再次展开长条输入框。
4. **比较分支**：任意卡片都能继续分叉；不同分支的问答互不共享后续内容。
5. **管理画布**：左侧侧边栏切换/新建/重命名/删除；追问统一在卡片输入区完成。
6. **创建与编辑笔记**：双击画布空白处创建笔记卡片；标题与正文双击进入编辑（单击让位给拖拽），正文编辑时按 Tab 插入 4 个空格；拖动四边或四角调整独立尺寸，笔记不参与自动整理与连线。
7. **调整外观与交互**：左下角「设置」包含三个选项卡：
   - **模型服务**：服务商（下拉选择 DeepSeek / OpenAI 兼容）、API Key、接口地址、模型、思考模式、建议数量；
   - **画布**：连接方式（直接分支 / 共用母线）、卡片间距（默认 80px，新建与自动整理共用）、指针区的滚轮逻辑、双击间隔、指针漂移延迟与距离、自动保存间隔与撤销步数；
   - **外观**：跟随系统 / 浅色 / 深色、正文字号（12–24px）、主题色相（可恢复默认）、连线粗细与颜色、12/24 小时制。
8. **撤销、保存与删除**：`Ctrl+Z` 撤销当前画布的上一步操作（按画布隔离，包含卡片尺寸修改）；`Ctrl+S` 保存当前画布；自动保存按设置定时执行，保存不会清空撤销记录；选中一张或多张卡片后按 `Delete` 可快速删除（元问题卡片仍不可删除）。

## 键盘操作优先级

当一个按键同时满足多个可执行动作时，始终**优先执行最后执行 / 最后打开的那个**；再次按下该键时依次回退到更早的动作。

例如同时展开两张卡片的「参考资料」抽屉，第一次按 `Esc` 收起后打开的那张，第二次按 `Esc` 再收起先打开的那张。

该约定适用于所有新增快捷键与浮层。实现使用统一的 Escape 动作栈（`frontend/src/lib/escapeStack.ts`），新增浮层请复用，不要单独注册 `window` 级 Esc 监听。更多开发约定见 [docs/development.md](docs/development.md)。

## 常见问题

- **卡片提示「未配置 API Key」**：打开左下角「设置」填写 Key 并保存，无需重启。
- **端口被占用**：后端可加 `--port 8001`，同时修改 `frontend/vite.config.ts` 的代理地址。
- **想清空全部数据**：停止后端，删除 `backend/data/app.db`，重新启动。
- **回答很慢/没有思考过程**：检查「设置」中的思考模式开关与模型名。
- **如何切换主题**：打开「设置 → 外观」，选择跟随系统 / 浅色 / 深色，并可调整主题色相、连线粗细与颜色。
- **如何撤销或保存**：在非输入框状态下按 `Ctrl+Z` 撤销当前画布的上一步（包含卡片尺寸修改），按 `Ctrl+S` 保存；选中卡片后按 `Delete` 可快速删除；自动保存间隔与撤销步数可在「设置 → 画布」中修改。
- **笔记卡片如何创建与调整大小**：双击画布空白处创建；拖动四边或四角手柄调整独立尺寸，标题与正文双击进入编辑（正文编辑时 Tab 插入 4 个空格），删除按钮在标题栏右侧。
- **只想改默认值**：编辑 `backend/.env` 后重启后端；页面里保存过的设置优先级更高。
- **`.env` 被忽略 / 提交被钩子拦截**：这是预期行为，环境变量文件与疑似 Key 不应入库。请把真实 Key 留在本地被忽略的 `.env` 中，只提交 `.env.example` 这类不含密钥的模板；钩子会列出命中文件，在该文件移除 `sk-` 开头的 Key 或非空的 `DEEPSEEK_API_KEY` 后重新提交。
